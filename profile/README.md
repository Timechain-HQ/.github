# Timechain HQ

Timecoin testnet repositories. These are not mainnet.

| Repository | Role |
| --- | --- |
| [Timecoin](https://github.com/Timechain-HQ/Timecoin) | Node, notes, blocks, and fork choice |
| [book](https://github.com/Timechain-HQ/book) | Protocol book |
| [wallet](https://github.com/Timechain-HQ/wallet) | View keys, scanning, payment, and sweep |
| [contracts](https://github.com/Timechain-HQ/contracts) | Contract machine and the vault |

The testnet id is `timecoin-testnet`. Notes use ML-DSA-44 and ML-KEM-768. Amounts stay public so every node can check conservation. There is no peer-to-peer network in this version.
